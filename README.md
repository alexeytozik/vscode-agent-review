Agent Review для VS Code: после ответа сама открывается вкладка с полным файлом и правками Codex, жмёшь Undo или Keep — и дальше к следующей. Один раз запускаешь Agent Review: Connect, открываешь `/hooks` в Codex CLI и разрешаешь хуки. Внизу Review: ON/OFF — нажал и переключил. Патчить VS Code больше не нужно.
