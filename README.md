Agent Review для VS Code: оставляешь или откатываешь правки Codex прямо в файле, дальше само кидает на следующее изменение. Один раз запускаешь Agent Review: Connect, открываешь `/hooks` в Codex CLI и разрешаешь хуки. Внизу Review: ON/OFF — нажал и переключил. Пока Preview; [установка и ограничения](docs/setup.md).
